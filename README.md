# Amazon Brazil Sales Analysis Using SQL

## 📖 Project Overview

This project presents an end-to-end SQL analysis of the **Amazon Brazil (Olist) E-commerce Dataset**. The objective is to transform raw transactional data into meaningful business insights by writing optimized SQL queries that analyze customer behavior, product performance, sales trends, seller efficiency, payment preferences, and delivery performance.

The project demonstrates practical SQL skills used in real-world business intelligence and data analytics environments.

---

## 🎯 Business Objectives

- Analyze overall sales performance.
- Identify top-performing product categories.
- Understand customer purchasing patterns.
- Evaluate seller performance.
- Examine payment behavior.
- Analyze order delivery performance.
- Generate actionable business insights for decision-making.

---

## 📂 Dataset Information

The project is based on the **Olist Brazilian E-commerce Dataset**, containing transactional data from a Brazilian online marketplace.

### Dataset Summary

| Table | Description |
|--------|-------------|
| Customers | Customer information |
| Orders | Order details |
| Order Items | Products purchased in each order |
| Products | Product information |
| Sellers | Seller details |
| Order Payments | Payment methods |
| Order Reviews | Customer ratings |
| Geolocation | Customer & Seller locations |
| Product Category Translation | Portuguese to English categories |
| Leads Qualified | Marketing qualified leads |
| Leads Closed | Converted seller leads |

The dataset contains 11 relational tables covering customers, orders, products, sellers, payments, reviews, and logistics. :contentReference[oaicite:0]{index=0}
